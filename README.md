# Ghostrunner Mission

Build a highly immersive, cinematic interactive anniversary website for my boyfriend Priyanshu.

This is a PERSONAL 5TH MONTH ANNIVERSARY SURPRISE.

The entire experience should feel like entering a futuristic cyberpunk game world inspired by Ghostrunner, because Ghostrunner is Priyanshu's favorite game and Jack is his favorite character.

IMPORTANT:
Do NOT make this look like a generic Valentine's Day website.
Do NOT use hearts, roses, pink gradients, cheesy romantic templates, floating heart animations, or a standard portfolio/card layout.
The romance should be hidden inside a dark futuristic cyberpunk experience.

The website should feel like a SECRET MISSION created specifically for Priyanshu by Kashvi.

==================================================
CORE VISUAL DIRECTION
=====================

Overall aesthetic:

* Dark futuristic cyberpunk
* Ghostrunner-inspired atmosphere
* Dystopian megastructure / Dharma Tower feeling
* Black / near-black background
* Neon red as the primary accent
* Cyan/blue secondary glow
* White/light-gray typography
* CRT scanlines
* Digital noise
* Glitch effects
* Terminal interfaces
* HUD overlays
* Holographic panels
* Futuristic monospace typography
* Subtle screen distortion
* Fast but elegant transitions
* Cinematic lighting
* Atmospheric particles
* Very high-quality game UI feeling

The interface should feel like an actual futuristic game terminal.

Use Jack/Ghostrunner visual references or assets that I provide. If no official asset is available, create an ORIGINAL futuristic runner silhouette inspired by the atmosphere, but do not invent a random fantasy warrior.

Jack should feel like an important recurring presence throughout the experience.

==================================================
TECHNICAL REQUIREMENTS
======================

Build this as a polished responsive website.

It must work beautifully on:

* Desktop
* Laptop
* Mobile

Use smooth animations and transitions.

Avoid excessive animations that make text difficult to read.

Use:

* CSS animations
* Framer Motion where appropriate
* Glitch transitions
* Typewriter effects
* Scanline overlays
* CRT effects
* Terminal typing
* Progress bars
* Loading sequences
* HUD elements
* Interactive buttons

The website should feel fast and intentional rather than overloaded.

SCREEN 4 — THE LOVE LETTER
==========================

This is the emotional heart of the website.

When "DECRYPT MESSAGE" is clicked, the intense cyberpunk UI should become calmer.

Keep the futuristic environment, but reduce the glitches and visual noise so the letter is comfortable to read.

Display the love letter as an encrypted memory file.

Header:

SOURCE: KASHVI
RECIPIENT: PRIYANSHU
STATUS: DECRYPTED

Then reveal the following letter with a beautiful typewriter animation, paragraph by paragraph:

You're my boyfriend, but you're also the person I want to tell random things to, the person I want to bother for absolutely no reason, the person I want to share my happiness with, and the person I look for when I just need someone.

I don't think I always say it properly, but I really do appreciate you.

I appreciate the little things.
The conversations.
The time you give me.
The way you became part of my everyday life without me even realizing how much I'd started depending on your presence.

And yes, sometimes you make me want to throw you out of a window. 😭
But unfortunately for you, you're stuck with me.

Because I love you.

I love you when you're being sweet.
I love you when you're being annoying.
I love you when you're making me laugh.

Because I'm not planning on letting this mission end anytime soon. ❤️

More than this little website could ever possibly put into words.

Happy 5 months, Priyanshu.

Always your Kashvi. ❤️"

Do not display the entire letter instantly.
Reveal it progressively using a typewriter / terminal decryption effect.
